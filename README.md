Emberline is a complete round-based tactical FPS in the browser: five Ember attackers against five Ashen defenders on Foundry District, an original dusk-industrial plant with two bombsites (Furnace and Depot), a mid lane and long corridors. Plant or defuse the bomb, earn money each round, spend it in the buy menu on four original weapons, armour and three grenade types, and outplay bots that follow routes, hold angles and react to what they see and hear. Fixed-step simulation, hitscan gunplay with headshot bonuses, recoil and spread that punish firing on the move, and a full HUD with health, ammo, timer, score, kill feed and bomb status. Built with three.js 0.187.0, offline from static files.

## Run it

```sh
node serve.ts
```
